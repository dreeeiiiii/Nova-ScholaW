# Existing UI fonts

These Latin-subset variable WOFF2 files were copied, unmodified, from the project's existing Next.js development cache. No new font download was made.

- `dm-sans-latin.woff2`: DM Sans, weight axis 100–1000; previously `5c285b27cdda1fe8-s.p.2_mbdogr7ni8i.woff2`.
- `raleway-latin.woff2`: Raleway, weight axis 100–900; previously `c825fd02acae0153-s.p.1q3-y3vmyf3p6.woff2`.

The corresponding cached CSS identifies both files as the Latin subsets of the existing Google Fonts configuration. Font metadata was checked with Next.js's bundled font parser. These are required typography assets, not school photographs.

Both fonts use SIL Open Font License 1.1. See `OFL.txt`; upstream notices are at https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt and https://github.com/google/fonts/blob/main/ofl/raleway/OFL.txt.
